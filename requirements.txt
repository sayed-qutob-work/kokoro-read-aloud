# Default install -- CPU build of PyTorch.
#
#   env\Scripts\python.exe -m pip install -r requirements.txt
#
# If the machine has an NVIDIA GPU, install requirements-cuda.txt INSTEAD.
# This is not a nice-to-have. On the reference laptop the CPU build synthesizes
# at 1.77x realtime while playback at the shipped speed drains 1.8x -- i.e.
# BELOW break-even, so long reads stall for seconds. The CUDA build measured
# 25.03x RT for 348MB of VRAM (AUDIT.md, 2026-08-11).
#
# Nothing else changes between the two: there is no device-selection code in
# tts_server.py, so kokoro takes the device from whichever torch build is
# installed.
#
# On CPU, lower the reading speed in the tray's Settings panel until the
# "sustainable speed" warning clears -- see README, "CPU or GPU".
-r requirements-base.txt
torch==2.13.0
